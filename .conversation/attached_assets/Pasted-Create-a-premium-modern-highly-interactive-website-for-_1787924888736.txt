Create a premium, modern, highly interactive website for THEYAQUA (PVT) LTD, an agricultural water and irrigation engineering company.

COMPANY
Name: Theyaqua Pvt Ltd
Industry: Agriculture, Irrigation & Water Engineering
Core focus: Agricultural irrigation systems, water storage, solar-powered water solutions, sprinklers, boreholes and related agricultural water infrastructure.

The website should transform the company's existing social-media presence into a professional company website that immediately communicates trust, technical expertise and agricultural capability.

BRAND DIRECTION
Use the company's existing logo and visual identity from the provided reference images.

Primary visual language:
- Deep agricultural blue
- Fresh green
- Warm yellow/gold accents
- White / very light backgrounds
- Dark navy for typography
- Subtle gradients where appropriate

Do NOT make the website look like a generic corporate template. It should feel like a premium African agricultural engineering company with strong technical credibility.

DESIGN STYLE
Create a visually impressive, modern website inspired by high-end technology, engineering and agricultural websites.

Use:
- Large cinematic hero sections
- Strong typography
- Massive headlines
- Generous whitespace
- Rounded cards
- Subtle glassmorphism where appropriate
- Layered sections
- Soft shadows
- Premium image treatment
- Smooth transitions
- Interactive hover states
- Scroll-triggered animations
- Subtle parallax
- Image reveal animations
- Animated counters
- Staggered content entrances
- Magnetic-style buttons where appropriate
- Smooth page transitions

The animations must feel intentional and premium, NOT excessive or distracting.

DESIGN SKILLSET
Apply these design principles throughout:

1. DESIGN TASTE
Prioritize visual hierarchy, spacing, typography, composition, contrast and consistency. Every section should feel deliberately designed rather than generated from a template.

2. PREMIUM UI/UX
Create a polished interface with excellent responsive behavior, intuitive navigation, clear CTAs and strong conversion-focused layouts.

3. MOTION DESIGN
Use Framer Motion or an equivalent animation system for:
- Scroll reveals
- Text animations
- Image reveals
- Card hover effects
- Section transitions
- Number counters
- Button interactions
- Subtle parallax effects

4. VISUAL STORYTELLING
Use the company's agricultural imagery to tell a story:
Problem → Water → Irrigation → Technology → Agricultural productivity → Results.

5. THREE.JS / WEBGL
Use Three.js only where it genuinely improves the experience. Consider a subtle interactive water/particle effect, agricultural terrain visualization or flowing-water visual in the hero/background.

Do NOT turn the website into a 3D gimmick.

6. RESPONSIVE DESIGN
The website must be exceptional on:
- Desktop
- Tablet
- Mobile

Mobile should not simply be a compressed desktop layout. Rework sections where necessary for mobile usability.

7. MICRO-INTERACTIONS
Add subtle interaction feedback to:
- Buttons
- Navigation
- Service cards
- Project cards
- Images
- Contact elements
